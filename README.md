# Round Table International 2027

A lightweight landing page for the Round Table International event, designed to be published directly via GitHub Pages.

## Local preview

Open the project folder in a browser, or run a quick local server from the project root:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## GitHub Pages deployment

1. Push this folder to a GitHub repository.
2. In the repository settings, open **Pages**.
3. Select the branch to publish (for example, `main` or `master`).
4. Choose the root folder, or the `/` folder if using the repo root.
5. Save.

If your repo is named something like `round-table-2027`, the site will be available at:

```text
https://<your-username>.github.io/round-table-2027/
```

## Customize content

Edit the copy and sections in `index.html` and the design in `styles.css`.

## Notes

This is a static site and works well with GitHub Pages without any build step.
